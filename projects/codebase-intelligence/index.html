What does Codebase Intelligence actually do? +

It helps developers navigate an unfamiliar Python project without pasting the entire repository into a chatbot.

Read the structure

The Python engine parses functions and classes and maps calls between them.

Find useful context

Keyword and semantic search find relevant code. The graph adds connected functions.

Explain with evidence

Gemini uses that context to answer questions, with source files and line references.
