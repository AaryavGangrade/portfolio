# Aaryav Gangrade — Creative Engineering Portfolio

An expressive, motion-led portfolio showcasing software engineering, AI, and data projects.

**Stack:** semantic HTML, CSS, JavaScript, and SVG. No build step, API keys, package installation, or framework required.

## Run locally

Open `index.html` in a browser, or use a local HTTP server:

```bash
python -m http.server 8000
```

Visit http://localhost:8000.

## Deploy to GitHub Pages

In this repository, go to **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. The site will be hosted at `https://aaryavgangrade.github.io/portfolio/` after publishing completes.

You can also import this repository into Netlify or Vercel as a static site. No build command is necessary.

## Included projects

Featured: Codebase Intelligence (agentic hybrid RAG), RetailLake (PySpark/Delta lakehouse), NSE Pattern Scanner, SteelOpt (synthetic educational nesting POC), Vireo Audio (support intelligence), and Kestrel Review (warranty triage). Additional work appears in the archive. Project descriptions distinguish prototypes and synthetic test data from production deployments.

## Editing

- `index.html` — sections, project cards, headlines, GitHub links, metadata
- `assets/styles.css` — design system, animations, layouts, and responsiveness
- `assets/main.js` — project case-study descriptions, filters, dialogs, interactions
- `assets/favicon.svg` — browser icon

## Accessibility and motion

The portfolio includes accessible dialogs and keyboard navigation, focus indicators, and support for reduced-motion preferences.

Inspired by the fluid/motion-led reference shared for this project. This implementation is original and does not contain extracted code from that website.
